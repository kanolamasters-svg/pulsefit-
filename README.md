# M.A.C. FITNESS

Aplicativo Android de treino em Jetpack Compose.

## Como abrir
1. Clique em Code > Download ZIP e extraia o arquivo.
2. Abra o Android Studio e escolha Open.
3. Selecione a pasta MAC-Fitness e aguarde o Gradle sincronizar.
4. Execute no emulador ou celular Android.

Pacote: `com.example.macfitness`.

Primeira versão: painel inicial, biblioteca com busca e filtros, detalhes de exercícios, séries e descanso.
